## New in Windows voice tools

- **[Vibe Voice Lite](https://github.com/UtenKekkoDev/vibe-voice-lite)** builds on Vibe Coding Voice. Hold Right Ctrl to dictate into a Windows text field, or use the interview mode to turn a spoken feature request into agreed requirements and open questions. [Windows preview downloads](https://github.com/UtenKekkoDev/vibe-voice-lite/releases) · [English guide](https://github.com/UtenKekkoDev/vibe-voice-lite/blob/main/README.en.md)
- **[Vibe Desktop Assistant](https://github.com/UtenKekkoDev/vibe-desktop-assistant)** extends Vibe Voice Lite as a separate Windows app. Hold F9 to name a control in the active window or dictate a draft into the current chat. For supported actions, the assistant reads back the field or checks the conversation for a matching message. [Source and setup](https://github.com/UtenKekkoDev/vibe-desktop-assistant#本机运行)

## What I care about

- **Clear agent interactions.** Make task state, progress, errors, and recovery understandable.
- **Repeatable workflows.** Turn useful experiments into tools that can be configured, reused, and maintained.
- **Local ownership.** Keep data portable and make the choice between local and online processing explicit.
- **Human control.** Give people useful feedback and a way to inspect, edit, or override the result.
